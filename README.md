# Intelligent Personal Finance Advisor — ML Pipeline Edition 🚀

A production-grade, full-stack machine learning project for personal finance. This application demonstrates an end-to-end ML pipeline with a React frontend and a FastAPI backend powered by scikit-learn and XGBoost. It includes automated retraining (CI/CD), experiment tracking with MLflow, and robust inference endpoints.

## 🧠 Backend: ML Pipeline (FastAPI)

The backend provides the intelligence for the advisor.

### Features
1. **Stock Direction Predictor (XGBoost):** Predicts the next-day direction (Up/Down) of major tech stocks, trained on historical OHLCV data with technical indicators (RSI, MACD, Bollinger Bands) computed with *no look-ahead bias*.
2. **Portfolio Risk Scorer (Linear Regression):** Computes Sharpe ratio, volatility, and max drawdown to score user portfolios.
3. **Transaction Anomaly Detector (Isolation Forest):** Identifies unusual spending patterns using an unsupervised anomaly detection model.
4. **Automated Retraining (CI/CD):** A safe retraining pipeline that downloads the latest market data, trains a new XGBoost model, and deploys it *only* if its F1-score matches or beats the current production model.
5. **Experiment Tracking:** Uses `mlflow` to log parameters, metrics, and models.

### Setup & Run
```bash
cd ml-backend
pip install -r requirements.txt
uvicorn main:app --reload
```
The ML API will be available at `http://localhost:8000`.
You can view the MLflow UI by running `mlflow ui --backend-store-uri ./mlruns` from inside the `ml-backend` directory.

## 🌐 Frontend: React Application

The frontend is a modern React application built with Vite, providing an interactive dashboard and a dedicated "ML Hub".

### Features
- **Dashboard & Analytics:** View expenses, insights, and goal tracking.
- **ML Hub Page:** An interactive dashboard consuming the ML API:
  - **Stock Predictor Widget:** Select a ticker and days to predict, view confidence bars and top feature importances.
  - **Portfolio Risk Widget:** Enter custom stock weights and receive an AI-driven risk score via an interactive gauge.
  - **Model Health Dashboard:** View backend uptime, last retrain time, model F1 score, and retraining history. Includes a manual trigger for model retraining.

### Setup & Run
```bash
# In the root directory
npm install
npm run dev
```
Open `http://localhost:5173` (or the port Vite outputs) in your browser.

**Environment Variable:** Ensure `VITE_ML_API_URL` is set to `http://localhost:8000` in your frontend environment (e.g. `.env`) so it can connect to the local ML backend.

## 🤖 CI/CD & Automation

This repository includes GitHub Actions workflows to automate testing and retraining.

- **`test.yml`**: Runs Pytest on the ML backend on every push to `main` and Pull Requests. Ensures data pipelines, feature engineering schemas, and API endpoints function correctly.
- **`retrain.yml`**: A scheduled job that triggers the backend's retraining pipeline, simulating a production MLOps workflow.
